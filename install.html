Install Unbound Infotech

iPhone / iPad (Safari)

  1. Open the app in Safari (not Chrome/in-app browsers).
  2. Tap the Share button (square with arrow).
  3. Choose Add to Home Screen, then Add.
  4. Launch it from the home-screen icon; it runs full-screen and works offline with your last data.
  5. Optional: Settings → Notifications → allow, while the app is open (iOS 16.4+).

Android

Install the APK from the GitHub release, or in Chrome use ⋮ → Install app.

Live data on the web version

Browsers block direct requests to market/news sources. In the app open More → Settings → Web app data proxy and paste your own free Cloudflare Worker URL (script: mobile/tools/cors-worker.js). Without it the app still works for the paper portfolio, journal, jargon and sync, but quotes/news won't load.
